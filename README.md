# AI/ML Internship Task 2 – Exploratory Data Analysis

## Objective
To understand the Titanic dataset using statistical analysis and data visualization.

## Dataset
Titanic dataset containing passenger information such as PassengerId, Survived, Pclass, Age, SibSp, Parch, Fare, and other features.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Tasks Performed
- Loaded and explored the Titanic dataset.
- Displayed the first few rows and dataset information.
- Generated summary statistics.
- Created histograms for numerical features.
- Created boxplots to identify data distribution and possible outliers.
- Generated a correlation matrix to study relationships between numerical features.
- Observed patterns and relationships in the dataset.

## Files
- `task2.py` – Python code used for EDA.
- `Titanic-Dataset.csv` – Dataset used for analysis.
- `task2.png` – Histogram output.
- `task2 1.png` – Boxplot output.
- `task2 2.png` – Correlation matrix output.

## Conclusion
Exploratory Data Analysis helped in understanding the distribution of the Titanic dataset, identifying outliers, and observing relationships between numerical features.
